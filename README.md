# TechMirus

Building node.js skills with Software company management app.

## API Routes

#### Auth Routes

- `POST` /signUp - _Create employee account and signUp_
- `POST` /logIn - _Login as existing employee_
- `POST` /logout - _Logout employee_

#### Employee Routes

- `GET` /employee - _Get the employee data with email_
- `GET` /employee/profile - _Get the logged in employee data_
- `GET` /employees - \_Get all employees
- `PUT` /employee - _Update employee profile_
- `DELETE` /employee - _Delete employee profile_
- `POST` /changePassword - _Change employee password_
